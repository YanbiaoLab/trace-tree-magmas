# arXiv priority and CADE/CAV/FM submission note

Audit updated: 2026-09-04

An arXiv release establishes a public chronology for the authors' result.  A
later ETP update incorporating those certificates does not make the discovery
someone else's prior work.  In a conference version, novelty should be stated
relative to the dated pre-release ETP/ALPS snapshot, and the arXiv v1 should be
identified as the first public disclosure.

The currently visible 2027 policies are incomplete:

- CAV 2027 lists a 2027-01-20 submission deadline but its detailed call is not
  yet posted.  CAV 2026 explicitly did not discourage arXiv posting, while
  recommending against posting within one week before or one month after the
  deadline because of double-blind review.  A 2026-09 arXiv release is well
  outside that cited window, but the CAV 2027 call remains controlling.
- CADE-31 is announced for August 2027, but no 2027 call or preprint policy is
  currently posted.  CADE-30 required unpublished work and prohibited
  simultaneous submission elsewhere, but did not explicitly classify arXiv
  in its call.
- FM 2027 is listed for 18--22 October 2027, but no research-paper call is
  currently posted.  FM 2026 used single-blind review and required original
  work not published or submitted elsewhere, without an explicit arXiv clause
  in the public call.

Therefore the current practical conclusion is: arXiv does not erase the
priority or an appropriately dated classification claim, but eligibility must be rechecked
against each venue's final 2027 call.  If CADE-31 or FM 2027 retains ambiguous
"unpublished" wording without a preprint clause, request a written ruling from
the program chairs before submission.

For a double-blind venue, follow that venue's exact self-citation rule.  A safe
scientific formulation is third-person and chronological: the ETP snapshot
left the identities open; the dated preprint first supplied the certificates;
the later ETP commit incorporated them.
