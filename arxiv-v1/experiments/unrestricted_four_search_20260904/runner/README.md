# Remote Sandbox runner

`run_isolated_search.py` wraps the vendored Stage-2 runtime.  It recognizes an
explicit completed-without-candidate frame, classifies narrowly evidenced
process-tree memory kills as resource limits, and raises the post-competition
certificate capture ceiling to 1,024,000 bytes.

`run_campaign.py` runs all six final executable profiles.  Trace receives the
full 4,187 input; guarded, the three completion profiles, and CNF receive their
documented supplemental subsets.  Every profile independently encodes a
120-second search budget.

Copy `.env.example` to an untracked `.env` and replace its placeholders.  Never
commit credentials, private service URLs, CA material, raw run logs, or Sandbox
pool files.  See the top-level `REPRODUCIBILITY.md` for commands.
